# Totais do Período incluem lançamentos futuros com data no recorte

Ganhos, gastos e Saldo somam lançamentos ativos cuja data cai no Período, mesmo que a data ainda não tenha chegado. Não há “realizado até hoje” nem dois números (realizado vs previsto) nesta fase. O livro já aceita data futura e gera parcelas à frente; o Painel mostra o recorte inteiro, não o YTD. Compra desfeita (soft delete) não entra.
